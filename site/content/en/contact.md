# Contact and support for kmsg

Use the public GitHub repository for kmsg bug reports, feature requests, setup questions, and MCP integration help. Public issues create a searchable record tied to source revisions and releases. The project does not operate a paid help desk, telephone support line, or guaranteed response-time service.

## Bugs and general support

Open an issue at [GitHub Issues](https://github.com/channprj/kmsg/issues). Include the kmsg, macOS, and KakaoTalk versions; the command you ran; expected and actual behavior; and a minimal reproduction. Before attaching Accessibility output or logs, remove names, chat text, phone numbers, account identifiers, local paths, credentials, and keys. Prefer synthetic examples to real private messages.

## Feature and developer questions

Describe the real job a proposed command, JSON field, MCP tool, or document should solve. State side effects, approval boundaries, and expected failure behavior. Check the developer resources, architecture, current issues, and release notes first so the discussion can build on existing contracts.

## Security and privacy

Do not publish a sensitive vulnerability or private personal data in a public issue. Send the minimum necessary report to `iam@chann.dev` with `kmsg security` or `kmsg privacy` in the subject. Include affected versions and reproduction conditions, but never send a real KakaoTalk password, message archive, access token, or encryption key. Ordinary support may be redirected to a public issue.

## Official references

The official source is `https://github.com/channprj/kmsg`, the canonical site is `https://channprj.github.io/kmsg/`, and the maintainer profile is `https://github.com/channprj`. Verify binaries through GitHub Releases or the `channprj/tap` Homebrew tap. Changes to contact details or policy are recorded in this page and repository history.
